# Diar App (دیار اپ) - Financial Dashboard

Diar App is a localized, fully containerized Django web application designed for managing projects, tracking financial expenses, and storing receipt images. 

It features a beautiful RTL Persian interface using Bootstrap 5 and Vazirmatn typography, custom session management, and robust deployment using Nginx, PostgreSQL, and Docker.

---

## 🚀 Prerequisites

Before you begin, ensure you have the following installed on your machine:
* **Git** (To clone the repository)
* **Docker & Docker Compose** 
  * *Windows/Mac:* Install [Docker Desktop](https://www.docker.com/products/docker-desktop/). Make sure it is running in the background.
  * *Linux:* Install Docker Engine and the Docker Compose plugin.
